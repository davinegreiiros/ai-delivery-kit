# ai-delivery-kit

Esta extensão fornece as skills `kit-*`. Em repositórios que usam o kit (o `AGENTS.md` cita o
ai-delivery-kit ou existe `.kit/constitution.md`), toda mudança de código, testes, configuração ou
comportamento segue a skill `kit-sdd`; bugs sem causa conhecida começam por
`kit-systematic-debugging`. Para preparar um repositório novo, use `kit-project-bootstrap`.
